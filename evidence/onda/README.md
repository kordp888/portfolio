# ONDA 속도 계산 회귀 증거

## 관측

실차 브라우저에서 연속 위치 표본의 센서 시각이 같게 들어오는 경우가 있었습니다.
기존 계산은 경과 시간이 0이어서 속도를 만들지 못했고, 속도에 의존하는 안내도
건너뛸 수 있었습니다.

## 재구성

`gps.samples.synthetic.json`은 실제 위치를 담지 않습니다. 두 표본 사이의 합성
이동 거리와 시각만 기록합니다. `legacy_speed`는 센서 시각만 사용해 실패를
재구성합니다. 이 파일은 옛 프로덕션 소스의 복사본이 아닙니다.

## 검증

`speed_with_fallback`은 센서 시각이 증가하면 이를 우선 사용합니다. 고정되거나
뒤로 가면 단조 증가하는 벽시계 경과 시간으로 전환합니다. 두 시각이 모두
증가하지 않으면 표본을 거부합니다.

```bash
python3 -m unittest evidence.onda.test_speed_fallback
```

합성 표본의 기대 결과는 `expected.legacy.json`과 `expected.fixed.json`에
고정했습니다. 최신 수정본의 최종 실차 재검증은 아직 끝나지 않았습니다.
브라우저 음성 엔진 실패와 음성 자산 권리 검사는 별도 릴리스 게이트입니다.
