# 공개 제거 규칙

이 디렉터리는 비공개 소스의 복사본이 아닙니다. 합성 입력과 그 입력으로 다시 만든
추적만 공개합니다.

공개하지 않는 항목:

- 이름, 연락처, 생년월일, 얼굴, 실제 음성
- 실제 주소, 위도·경도, 차량·기기 식별자, IP
- 채널명, 채널 ID, 영상 ID, 비공개 제목, 원본 분석 내역
- API 키, OAuth 토큰, 쿠키, 서명 URL, 환경변수 값
- 사용자 홈 절대경로, 비공개 저장소 URL과 브랜치명
- 기사 전문, 유료 콘텐츠, 음성 파일, 원본 카메라 데이터
- 원본 스택트레이스와 운영 로그

실패 재현은 `reconstructed`, 실제 관측은 `observed`, 현재 검증은 `verified`로
구분합니다. CI는 연락처, 절대경로, 토큰 형태, IP, 쿼리 문자열이 있는 URL을 찾으면
실패합니다.
