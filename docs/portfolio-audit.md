3. 사전 개발 허용 범위. 2026-10-16 두 대회의 요강·FAQ·공지를 다시 읽었습니다. 고용24는 개발 기간(10/23~11/5)만 적혀 있고, 그 전에 쓴 코드나 본인 기존 코드를 쓸 수 있는지는 언급이 없습니다. 외부 자원 활용은 자유이고 권리 책임은 참가자에게 있습니다. 공지는 0건입니다. 중복 응모 금지는 수상작뿐 아니라 다른 공모전 출품작에도 적용됩니다. 판단이 바뀌지 않았으므로 제출용 신규 기능 개발은 계속 보류합니다.
